# WULPUS GUI source files
This directory contains the source files for WULPUS Graphical User Interface (`sw/wulpus`) and example Jupyter notebooks.

# How to get started?

Install dependencies with `uv` and launch Jupyter from this folder:

```bash
uv sync
uv run jupyter notebook
```

For more details, see `sw/how_to_install_dependencies.md`.
